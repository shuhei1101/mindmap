## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 置き場所 | 動かさない。スキルの共通の置き場所を `skills/mindmap/` にしたため、`scripts/`・`schemas/`・`preview/` は今の場所のまま | インターフェース定義『話し合いの進行』の共通の置き場所 |
| 入口の起動し直し | `mindmap.py` を起動した Python が 3.12 以上で PyYAML・jsonschema を読み込めればそのまま実行し、読み込めなければ `check-env` 以外のコマンドをスキル専用の仮想環境の Python で 1 回だけ起動し直し、標準出力・標準エラー・終了コードをそのまま返す。仮想環境が無い・仮想環境にも依存が無いときは `check-env` を促してエラー（終了コード 1） | スキルの `allowed-tools` を `Bash(python3 ${CLAUDE_PLUGIN_ROOT}/skills/mindmap/scripts/mindmap.py:*)` の 1 行にするため（[スキル](./スキル.md) の `## PoC 結果`）。インターフェース定義『コマンドの起動』 |
| ゴール判定のコマンド | `goal` を足す。`mindmap.yaml` のフェーズの並びとゴールのフェーズから、ゴールのフェーズまでの検討事項が全て決定済み・対象外・取り下げで、ゴールの `deliverables` の資料が全て `done: true` かを判定し、届いたかと残りの項目を返す。どのファイルも書き換えない | 単一ユースケース『ゴール判定』。インターフェース定義『ゴール判定』 |
| 既存機能への影響 | 既存のコマンドの引数・出力・終了コードは変えず、既存の単体・結合・E2E テストが全て pass する | 起動した Python に依存があれば起動し直さないため、テストを動かす Python で起動する既存のテストはそのまま通る |
