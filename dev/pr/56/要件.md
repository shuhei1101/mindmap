# 要件

## 要望

- プラグインを配るフォルダ `plugins/mindstella/` の直下に `LICENSE` を置き、本文をリポジトリの直下の `LICENSE`（MIT・`Copyright (c) 2026 shuhei1101`）と一字一句同じにする
- `claude plugin install` で取り込まれたプラグインのフォルダの直下に `LICENSE` があり、その本文がリポジトリの直下の `LICENSE` と一致する
- 足した後も、取り込まれたプラグインのフォルダに `dev/`・`docs/`・`tests/`・`.storybook/`・`package.json` が無く、hooks が 0 件である

`未確定`: 置き方（決める段: インターフェース定義設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 直下と `plugins/mindstella/` の 2 か所に同じ本文のファイルを置き、結合テストで 2 つの本文の一致を確かめる | どの環境の clone でも、インストールでも実体のファイルとして届く | 本文を直すときに 2 か所を直す（ずれは結合テストが捕まえる） |
| B | 直下の `LICENSE` を正にし、`plugins/mindstella/LICENSE` をそれを指すシンボリックリンクにする | 本文の正が 1 か所に決まる | `claude plugin install` がリンクを実体で写すかは未検証で PoC が要る。Windows の clone ではリンクが本文のパスだけのファイルになる |

推奨: A

ライセンスの本文はほぼ変わらず 2 か所を直す手間は小さく、リンクを写すかどうかの検証と Windows の clone での崩れを持ち込まずに済む。
