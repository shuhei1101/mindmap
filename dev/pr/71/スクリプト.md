## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| MCP のツール | `build` を除くコマンドを 1 コマンド = 1 ツールで移す。引数は今の `--json` の中身と同じキーを持つ入力にし、出力は今の標準出力の JSON を返す。失敗は今の標準エラーの内容をツールのエラーとして返す | MCP の実装は `未確定`（要件） |
| `build` | ツールにしない。配信が YAML を読むたびに今の `collect_preview_data` と同じ形の記録を組み立てる | - |
| プレビューの配信 | MCP サーバーのプロセスで `127.0.0.1` の HTTP を待ち受け、プレビューの HTML・スクリプト・記録の JSON を返す。ワークスペースの YAML が書き換わったら、開いている画面へ知らせる | 反映の方式は `未確定`（要件） |
| 送信 | 画面からの送信を受け、項目の ID・本文・送った時刻・取り込んだかをワークスペースに書く。取り込みのツールで未取り込みの一覧を返し、取り込み済みにする | 置き場所は `未確定`（要件） |
| 起動スクリプト | 依存を確かめ、tmux のセッションを立て、MCP サーバーを渡した Claude Code をその中で起動してつなぐ | 置き場所と呼び名はインターフェース定義設計で決める |
| エラー返却 | 配信の待ち受けのポートが使われているとき・tmux が無いときは、理由を示して止まる | - |
| 既存機能への影響 | `mindmap.py` のコマンドの入口を消す。`export` は MCP のツールで残す | 破壊的変更 |
| セキュリティ | 待ち受けは `127.0.0.1` だけにし、送信で受けるのは項目の ID と本文だけにする。本文はワークスペースへ書く前にスキーマと突き合わせる | - |
| 外部ライブラリ | MCP の SDK を足すなら、版を固定し、依存の確認の対象に足す | - |
