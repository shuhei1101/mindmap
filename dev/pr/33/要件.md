# 要件

## 要望

GitHub Pages（[https://shuhei1101.github.io/mindmap/](https://shuhei1101.github.io/mindmap/)）を、AI Monitor のドキュメントサイトと同じ共通のレイアウト・スタイルで配信する。

- AI Monitor の準拠バージョン（`ai-monitor-version.ini` の `v0.2.0`）のタグの時点の共通の部品を、内容を変えずに同じパスへ写す
  - `docs/_layouts/default.html`・`docs/_includes/sidebar-source.html`・`docs/_includes/tab-link.html`・`docs/assets/app.js`・`docs/assets/style.css`・`docs/search.json`・`docs/llms.txt`・`docs/_data/nav.yml`
  - 写した各ファイルが、AI Monitor の `v0.2.0` の同じパスのファイルとバイト単位で一致する
- `docs/_config.yml` を AI Monitor の `v0.2.0` のものを元に作り、`title` を `mindmap`、`description` を `mindmap の使い方と変更履歴`、`baseurl` を `/mindmap` に差し替える。他のキーとコメントは `v0.2.0` と同じにする
- `docs/_data/nav.project.yml` は今のものを使う
- `docs/index.md` を足し、サイトのトップに公開ドキュメントのタブ（はじめに・使い方・リファレンス）への目次を出す（`_config.yml` が `docs/README.md` をビルドから外すため、無いとトップが出ない）。書式は AI Monitor の `v0.2.0` の `docs/index.md` に揃え、行は [docs/index.yaml](https://github.com/shuhei1101/mindmap/blob/develop/docs/index.yaml) の `items` から取る
- Jekyll でビルドしたサイトで、トップとタブのページが共通のレイアウト（上タブ・サイドバー・検索）で描かれ、トップ・タブ・サイドバーのリンクが `/mindmap/` の下を指す

## 影響するユースケース

なし（公開ドキュメントのサイトの見た目だけを変え、プラグイン・スキル・スクリプト・プレビューの動きは変えない）
