## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 印 | 箱のアイコンの横の文字を `納品物` にする（詳細パネル・資料のカード） | クラス名 `deliv-badge` は変えない |
| 資料の絞り込み | 列の名前を `納品物`、値を `納品物`・`納品物以外` にする。URL の値も `f.deliverable=納品物` になる | キー `deliverable` は変えない |
| 概要のチェックリスト | 見出しを `納品物` にし、「すべて表示」は資料を `納品物` で絞って開く | |
| コメント | `style.css` と `.ts` のコメントの「成果物」を「納品物」にする | `.js` は tsc で生成し直して commit する |
