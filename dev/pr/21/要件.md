# 要件

## 要望

`build` が書き出す `preview.html` の画面を、見本 `tmp/preview-mock/`（ローカル、git の外）で決めた要件を落とさずに作る。
見本のコードは参考にとどめ、設計と規約に沿って作り直す。

### 見た目

- 無彩色の骨格に、強い色は印の 1 色（枝の線・選択・進み具合）だけを使う
- 見出しと本文の文字の大きさの差を大きく取り、角丸は 4px にする
- ライトとダークの両方を持つ
- 説明文を減らしてアイコンで伝え、押せるものと押せないものを見分けられるようにする
- ホバー・キーボードのフォーカス・選択中を、それぞれ見分けられる見せ方にする
- 素の JavaScript で書き、描画のライブラリ（marked・DOMPurify・elkjs・mermaid）は CDN から読む

### 画面

| 画面 | 要件 |
| --- | --- |
| 概要 | タイルを並べる: 次に検討する項目の上位 3 件 / ゴールまで（決定済みの数・フェーズごとの棒・成果物のチェックリスト。成果物が 5 件を超えたら、資料を成果物で絞り込んで開く）/ 要見直し / 保留（決定待ち・再開可能）/ 進行中のタスク / カテゴリー別の進み具合（フェーズを列にした表。セルを押すとその条件の一覧を開く）。要見直し・保留・進行中のタスクのタイルに「すべて表示」を置く |
| 検討事項 | マップ（既定）/ カード / 表 の順に切り替える。マップは下の「マップ」のとおり |
| タスク | ボード（既定。状態ごとの列で、完了・中止の列も出す。横にスクロールし、背景のドラッグで動かす）/ 表 |
| 調査・用語集・メモ・会話ログ | 表 |
| 資料 | カード（既定。成果物を先頭に印付きで並べる）/ 表。カードでも絞り込み（成果物 → 成果物以外の順・種類・カテゴリー・フェーズ・タグ）を使える |
| つながり | タブの帯の右端に分けて置く入口。下の「つながり」のとおり |
| 詳細パネル | 下の「詳細パネル」のとおり |
| 表（共通） | 下の「表」のとおり |
| 共通 | トップバーの検索（`/` で開き、Esc と外側の押下で閉じる）・ライト / ダークの切り替え・URL のハッシュに画面と開いている項目を持つ（お気に入りはこの URL で足りる）。タブにアイコンを付ける |

#### マップ

- 対象 → カテゴリー → フェーズ → 検討事項の木を、ELK で配置した直角の枝で描く
- 既定では決定済みを隠し、状態の印（色と形）を押して状態ごとに表示 / 非表示を切り替える
- 項目を押すと、根までの枝と、前提・後続の依存の線を強調し、ほかを薄くする。依存の線の上を小さな玉がゆっくり流れる
- 背景のドラッグで動かす。拡大・縮小・全体を表示のボタンは、マップの枠の外に固定する
- キーワードの検索を置き、名前に含む項目を黄色で強調し、当たった項目を含む状態の印にバッジを付ける
- 狭い幅では、字下げした縦の一覧にする

#### 詳細パネル

- 本文に重ねて出し、ゆっくりすべり込む。幅が 1680px 以上のときだけ、本文を寄せて並べる
- 全画面に切り替えると、画面の中央に、周りへ少し余白を空けたモーダルで出す
- 案はカードの縦並びにし、採用 / 不採用と理由を出す
- 前提・後続の項目・関連タスク・経緯・関連・この項目を参照している項目を出す
- 本文の Markdown と mermaid を描く。図には「拡大して見る」「Raw」「コピー」を置く
- 「拡大して見る」は、ホイールで拡大し、背景のドラッグで動かし、図の文字を選んでコピーできる

#### 表

- 並べ替え（昇順 → 降順 → 解除）
- 列ごとの絞り込み（値ごとの件数つき）と、かかっている条件のチップ
- 押した列までのピン留め（押した列のボタンだけが光る）
- 表示する列の選択と、初期設定に戻す
- 操作してもスクロールの位置を保つ

#### つながり

- 全種類の項目を、関連（依存・関連・根拠・タスクが進める検討事項）でつないで 3D で描く
- ライブラリを使わず、平たい円をキャンバスに透視で描く
- 上下左右に回せる。向きは目標へ毎コマ少しずつ寄せ、離すと慣性でゆっくり止まる。操作が止まって少しすると、ごくゆっくり自動で回る
- ホイールでマウスの位置へ寄る。拡大・縮小を繰り返しても中心がずれない（群れの中に収める、全体まで離れたら戻す、背景のダブルクリックで戻す）
- カーソルを乗せると、その玉は動かず、つながる玉がゆっくり寄ってきて、ほかはゆっくり薄くなる
- 押すと、そこへゆっくり寄って詳細を開き、つながる線の上を小さな玉がゆっくり流れる
- 文字は玉と同じ倍率で大きさが変わり（玉の幅に英字 6 文字ほど）、玉の上に置く。遠いと薄く、ある距離で消える。フォントの大きさは固定し、倍率は描くときにかける
- 何も選んでいないときも、つながる玉どうしをごく薄い線で結ぶ
- 色は種類で分ける（検討事項・タスク・調査・資料は色、用語集は濃い灰・メモは茶・会話ログは薄い灰）
- 地は、ライトでは紙のような明るい地にざらつき、ダークでは墨色に淡い光のにじみ
- 画面の外の玉・線・文字は描かない
- つながりの種類ごとの表示 / 非表示で、表示中と非表示を見分けられるようにする

### 動きと文言

- 自動で動くアニメーションは入れない。動くのは、選んだときの線の流れと、つながりだけにする。どれも速すぎないこと
- 文言は自然な日本語で書く（[shuhei1101/ai-monitor#2363](https://github.com/shuhei1101/ai-monitor/issues/2363) の決まり）

### 持ち越した課題

- 表示形式の切り替えのボタンを、どのタブでも同じ位置・同じ幅にし、切り替えでちらつかせない
- つながりの拡大・縮小とスクロールの重さを解く（数値の基準は非機能要件で決める）

| 項目 | 理由 | 対応予定 |

| 詳細パネルの入れ子の展開（行の中に案の表を開く） | Issue で入れないと決めた | 予定なし |

| 書き込む操作（回答・意見の送信・項目の編集） | 要望は読み返す画面で、書き込みはサーバーでの配信が前提になる | [#13](https://github.com/shuhei1101/mindmap/issues/13) |
| 記録の差分の表示 | 要望に含まれない | [#13](https://github.com/shuhei1101/mindmap/issues/13) |
| ライブラリ・データを中に持つ、配る用の 1 枚の HTML | この PR の画面を前提にした後続 | [#19](https://github.com/shuhei1101/mindmap/issues/19) |
| 画面の文言の 1 語ずつの点検と「成果物」→「納品物」の呼び替え | この PR の画面を前提にした後続 | [#6](https://github.com/shuhei1101/mindmap/issues/6) |
