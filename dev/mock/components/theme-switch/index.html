ライト / ダークの切り替え

トップバーの右端に置くライト / ダークの切り替え。押す前後でラベル「ダーク」を変えない。見本のスイッチを押すと画面全体の明暗が切り替わる。

案 A: スイッチ・オフ（ライト）

ラベル「ダーク」の右に溝とつまみ。オフは溝を枠だけにし、つまみを左に置く。

mindmap要件出しのスキル mindmap を設計する

案 A: スイッチ・オン（ダーク）

オンは溝を印の色で塗り、つまみを右に送る。ラベルの文字も明るくする。

mindmap要件出しのスキル mindmap を設計する

案 A: ホバー

面の色だけを変える。

mindmap要件出しのスキル mindmap を設計する

案 A: キーボードのフォーカス

印の色の輪。ホバーと見分ける。

mindmap要件出しのスキル mindmap を設計する

案 A: 狭い幅（390px）

題名を隠し、検索の入口を虫眼鏡だけにした残りの幅に、ラベルと溝をそのまま置く。

mindmap要件出しのスキル mindmap を設計する

案 A: 最も狭い幅（320px）

ラベル「ダーク」を残したまま収まる。

mindmap要件出しのスキル mindmap を設計する

案 B: チェックボックス・オフ（ライト）

標準のチェックボックスにラベル「ダーク」を添える。トップバーの他の部品（枠や面で押せることを示すボタン）と形がそろわない。

mindmap要件出しのスキル mindmap を設計する

案 B: チェックボックス・オン（ダーク）

チェックを入れ、ラベルの文字を明るくする。

mindmap要件出しのスキル mindmap を設計する

案 B: 狭い幅（390px）

幅は案 A とほぼ同じ。

mindmap要件出しのスキル mindmap を設計する
