# スクリプト

スキルが呼ぶスクリプトのコマンド（引数・標準入力・標準出力・終了コード）

## 目次

| 分類 | ページ | 概要 |
| --- | --- | --- |
| 作る | [依存の確認](./依存の確認.yaml) | check-env: スキル専用の仮想環境の Python と PyYAML・jsonschema の版を確かめる |
| 作る | [ワークスペースの作成](./ワークスペースの作成.yaml) | init: 設定を受け取って空のワークスペースを作る |
| 書く | [項目の追加](./項目の追加.yaml) | add: 1 項目を足す |
| 書く | [項目の更新](./項目の更新.yaml) | update: 1 項目のキーを置き換える |
| 書く | [採用する案の切り替え](./採用する案の切り替え.yaml) | adopt: 検討事項の採用する案を 1 つに切り替える |
| 読む | [再開時の状況](./再開時の状況.yaml) | status: 要見直し・進行中・再開可能・決定待ち・次の候補をまとめて返す |
| 読む | [次の候補](./次の候補.yaml) | next: 前提が揃った未決定をフェーズ → 影響度 → 後続の件数の順に返す |
| 読む | [影響の洗い出し](./影響の洗い出し.yaml) | impact: 参照を逆向きにたどって影響を受ける項目を返す |
| 読む | [項目の検索](./項目の検索.yaml) | find: 条件に合う項目を返す |
| 読む | [項目の表示](./項目の表示.yaml) | show: 1 項目の中身・本文・参照元を返す |
| 読む | [属性名の一覧](./属性名の一覧.yaml) | attrs: 使っている属性名と件数を返す |
| 点検と書き出し | [ワークスペースの点検](./ワークスペースの点検.yaml) | check: スキーマ違反・参照切れ・本文のずれを洗い出す |
| 点検と書き出し | [プレビューの書き出し](./プレビューの書き出し.yaml) | build: 記録を埋め込んだ preview.html を書き出す |
| 作る | [コマンドの起動](./コマンドの起動.yaml) | python3 で起動したコマンドを、依存が無ければスキル専用の仮想環境の Python で起動し直す |
| 読む | [ゴール判定](./ゴール判定.yaml) | goal: ゴールのフェーズまでが決着し成果物が揃ったかと、残りの項目を返す |
| 点検と書き出し | [記録の形式の移行](./記録の形式の移行.yaml) | migrate: 前の版の形式の YAML（資料の done）を今の形式へ一度だけ書き換える |
