# プレビュー

ワークスペースの記録を `preview.html` に書き出し、利用者が開けるようにする。

## 手順

### 書き出す

`build` を呼ぶ。
出力の `path` が、書き出した `preview.html` の絶対パスになる。

### パスを示す

`path` の絶対パスを示し、ブラウザで開くよう案内する。

## 配る書き出し

利用者が記録を人に渡したいと言ったときだけ行う。ネットにつながらなくても開ける 1 枚の HTML を書き出す。

### 書き出す先を聞く

書き出す HTML のパス（末尾は `.html`）を利用者に聞く。
ワークスペースの `preview.html` と `release/` の中は選べない。

### 書き出す

`export --workspace {フォルダ} --out {パス}` を呼ぶ。
出力の `path` が、書き出した HTML の絶対パスになる。

### パスを示す

`path` の絶対パスを示す。
ネットにつながらなくても開けることと、記録を書き換える操作が無いことを添える。
