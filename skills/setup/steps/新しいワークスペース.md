# 新しいワークスペース

分野に合った軸とゴールを決めて、新しいワークスペースを作る。
問いは `${CLAUDE_PLUGIN_ROOT}/skills/mindmap/references/質問の書式.md` の書式で書き、文章は `${CLAUDE_PLUGIN_ROOT}/skills/mindmap/references/文章の書き方.md` に従う。

## 手順

### 分野を決める

何を話し合うかを尋ね、分野を決める。
分野ごとの進め方ガイドは `${CLAUDE_PLUGIN_ROOT}/skills/mindmap/playbooks/` にある（システム開発・調査・資料作り・壁打ち）。
話題に合う分野のガイドを Read で読む。
どの分野にも当てはまらないときは、進め方ガイドが無いことを伝え、近い分野のガイドで進めてよいかを尋ねる。

### たたき台を作って確認する

ガイドから、次のたたき台を作る。

| 項目 | たたき台の元 |
| --- | --- |
| 分野（`field`） | 選んだガイドの名前 |
| 最上位の軸の呼び名（`target_label`） | ガイドの `## 最上位の軸の呼び名` |
| フェーズ（`phases`） | ガイドの `## フェーズと観点` の並び |
| 対象（`targets`） | 話題から、名前と概要を 1 件以上 |
| カテゴリー（`categories`） | ガイドの `## カテゴリーの分け方` と話題から。各カテゴリーは `target` で対象を指す |
| ゴール（`goal`） | ガイドの `## ゴールの候補` の既定。`phase` と、成果物の題（`deliverables[].title`） |

ゴールの候補が複数あるので、候補を案の表にし、既定を推奨にして確認を取る。
対象・カテゴリーのたたき台は、直してもらう前提で示す。
利用者が確定するまで、ワークスペースを作らない。

### ワークスペースを作る

確定した設定の JSON を `--json` に渡して `init` を呼ぶ。

```
init --workspace {ワークスペースのフォルダ} --json '{"field": "システム開発", "target_label": "システム", "phases": ["目的", "要件"], "targets": [{"name": "家計簿アプリ", "summary": "支出を記録する"}], "categories": [{"name": "機能", "target": "家計簿アプリ", "summary": "利用者ができること"}], "goal": {"phase": "要件", "summary": "要件が決まる", "deliverables": [{"title": "要件定義書"}]}, "links": []}'
```

`init` が終了コード 1 で終わったときは、標準エラーの内容を示して止まる。

### プレビューを書き出す

ワークスペースを作ったので、最後に `build` を流す。

### 話し合いへ渡す

作ったワークスペースのフォルダを示し、`/mindmap:session {ワークスペースのフォルダ}` で話し合いを続けるよう案内する。
