# ゴール判定

ゴールのフェーズまでの検討事項と成果物が揃ったかを確かめ、利用者の確定を取って、`handoff/` に引き渡しの資料を書き出す。
問いは `${CLAUDE_PLUGIN_ROOT}/skills/mindmap/references/質問の書式.md` の書式で書き、文章は `${CLAUDE_PLUGIN_ROOT}/skills/mindmap/references/文章の書き方.md` に従う。

## 手順

### ゴールに届いたかを確かめる

`goal` を呼ぶ。

- `reached` が偽のとき、`remaining_decisions`（ID・題・フェーズ・状態）と `remaining_deliverables`（題・資料）を示し、次に決める検討事項を推奨する。`handoff/` には何も書かず、ここで終える
- `reached` が真のとき、「確定を取る」へ進む

### 確定を取る

決まった検討事項（ゴールのフェーズまでのもの。`decisions.yaml` を Read で読み、ID・題・`answer`・`reason`）と、ゴールの成果物（`mindmap.yaml` の `goal.deliverables` の題と、`doc` が指す資料）を示す。
確定してよいかを質問の書式で尋ねる。

- 確定されたら、「引き渡しの資料を書き出す」へ進む
- 直すと言われたら、取り込みの手順で直し、`goal` を呼び直す

### 引き渡しの資料を書き出す

進め方ガイドの `## 引き渡しの形` のとおり、`{ワークスペースのフォルダ}/handoff/` に Write ツールで書く（利用者に書き込みの確認が出る）。

- `決定事項.md`: 決まった検討事項の一覧をフェーズの順に並べる
- `{成果物の題}.md`: 成果物の資料ごとに、`show {資料の ID}` の `body_markdown` を本文にする

### 会話ログを書き足す

`add log` で会話ログを 1 件足し、`related` に成果物の資料を指す。

### プレビューを書き出す

最後に `build` を流す。

### 書き出したファイルを示す

`handoff/` に書いたファイルを示す。
