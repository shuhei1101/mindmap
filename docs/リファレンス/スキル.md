# スキル

プラグイン mindmap が持つスキルの一覧と、進め方ガイドの一覧。
どれも Claude Code のセッションでスラッシュコマンドとして呼び、ワークスペースへの記録は [コマンド](./コマンド.md) を呼んで行う。

## 一覧

| 名前 | コマンド | 説明 |
| --- | --- | --- |
| [話し合いをセットアップする](#話し合いをセットアップする) | `/mindmap:setup` | 依存を確かめ、新しいワークスペースを作るか、既存のワークスペースの状況を示す |
| [話し合いを進める](#話し合いを進める) | `/mindmap:session` | 取り込み・ヒアリング・リサーチ・方針転換・プレビュー・ゴール判定を回して、ゴールまで進める |

## 話し合いをセットアップする

依存を確かめ、新しいワークスペースを作るか、既存のワークスペースの状況を示して、`/mindmap:session` へ渡す。
スキルが自分でファイルを書くことはない。

### 使い方

```
/mindmap:setup [ワークスペースのフォルダ]
```

### 引数

| 引数 | 必須 / 任意 | 説明 | 例 |
| --- | --- | --- | --- |
| ワークスペースのフォルダ | 任意 | `mindmap.yaml` があれば既存のワークスペース、無ければ新しいワークスペースとして扱う。省略すると指定を求める | `~/discussions/家計簿アプリ` |

### ステップ

| ステップ | 手順 | 使うコマンド | することと残る記録 |
| --- | --- | --- | --- |
| 新しいワークスペース | [新しいワークスペース](https://github.com/shuhei1101/mindmap/blob/develop/skills/setup/steps/%E6%96%B0%E3%81%97%E3%81%84%E3%83%AF%E3%83%BC%E3%82%AF%E3%82%B9%E3%83%9A%E3%83%BC%E3%82%B9.md) | `check-env`・`init`・`build` | 題名・分野・最上位の軸の呼び名・フェーズ・カテゴリー・ゴールのたたき台を示して確定をもらい、ワークスペースを作る |
| 既存のワークスペース | [既存のワークスペース](https://github.com/shuhei1101/mindmap/blob/develop/skills/setup/steps/%E6%97%A2%E5%AD%98%E3%81%AE%E3%83%AF%E3%83%BC%E3%82%AF%E3%82%B9%E3%83%9A%E3%83%BC%E3%82%B9.md) | `check-env`・`status`・`find` | 要見直し・進行中・再開可能・次の候補を示し、続きを推奨する。ファイルは書き換えない |

依存が足りないときは、足りないものとそろえるコマンドを示して止まる。
どちらのステップも、最後に `/mindmap:session {ワークスペースのフォルダ}` で続けるよう案内する。

## 話し合いを進める

作成済みのワークスペースで、ステップを場面に応じて回す。

### 使い方

```
/mindmap:session [ワークスペースのフォルダ]
```

### 引数

| 引数 | 必須 / 任意 | 説明 | 例 |
| --- | --- | --- | --- |
| ワークスペースのフォルダ | 任意 | `mindmap.yaml` があるフォルダ。省略すると、同じ会話で `setup` が渡したフォルダを使う。どちらも無い・`mindmap.yaml` が無いときは、書き込まずに `/mindmap:setup` を案内する | `~/discussions/家計簿アプリ` |

### ステップ

ワークスペースを編集したステップは、最後に `build` を流してプレビューを書き出し直す。

| ステップ | 手順 | 使うコマンド | することと残る記録 |
| --- | --- | --- | --- |
| 取り込み | [取り込み](https://github.com/shuhei1101/mindmap/blob/develop/skills/session/steps/%E5%8F%96%E3%82%8A%E8%BE%BC%E3%81%BF.md) | `add`・`update`・`build` | 発言を対象・カテゴリー・フェーズに振り分けて記録し、派生の検討事項・未整理・タスクを積む。保留・解除・中止もここで行う。図や文書は資料に残し、会話ログを書き足す |
| ヒアリング | [ヒアリング](https://github.com/shuhei1101/mindmap/blob/develop/skills/session/steps/%E3%83%92%E3%82%A2%E3%83%AA%E3%83%B3%E3%82%B0.md) | `next`・`find`・`update`・`add`・`build` | 前提が揃った未決定を 1 ラウンドにまとめて聞き、答えを `answer` に入れて決定済みにする |
| リサーチ | [リサーチ](https://github.com/shuhei1101/mindmap/blob/develop/skills/session/steps/%E3%83%AA%E3%82%B5%E3%83%BC%E3%83%81.md) | `add`・`update`・`find`・`build` | 「何を・どの観点で・何体で」を示して確認を取り、サブエージェントで調べ、調査を元の検討事項に `related` で繋ぐ。利用者が自分から頼んだときは確認を省く |
| 方針転換 | [方針転換](https://github.com/shuhei1101/mindmap/blob/develop/skills/session/steps/%E6%96%B9%E9%87%9D%E8%BB%A2%E6%8F%9B.md) | `adopt`・`impact`・`update`・`add`・`check`・`build` | 採用する案を切り替え、影響を受ける決定済みの項目を要見直しにし、見直しのタスクを積む。納品物が要らなくなったときは、資料へ格下げする |
| プレビュー | [プレビュー](https://github.com/shuhei1101/mindmap/blob/develop/skills/session/steps/%E3%83%97%E3%83%AC%E3%83%93%E3%83%A5%E3%83%BC.md) | `build`・`export` | `preview.html` を書き出し、絶対パスを示す。ブラウザは開かないので、利用者が開く。利用者が記録を人に渡したいと言ったときだけ、書き出す先のパスを聞き、`export` で配る書き出し（ネットにつながらなくても開け、書き込む操作を持たない 1 枚の HTML）を書き出して絶対パスを示す |
| ゴール判定 | [ゴール判定](https://github.com/shuhei1101/mindmap/blob/develop/skills/session/steps/%E3%82%B4%E3%83%BC%E3%83%AB%E5%88%A4%E5%AE%9A.md) | `goal`・`show`・`clear-release`・`add`・`build` | ゴールに届いていれば、検討事項と納品物を示して確定をもらい、`release/` に書き出す。届いていなければ、残りを示す |

### 確認が出る操作

スキルが許す操作は、ファイルを読むことと、サブエージェントによる調査と、スクリプトのコマンドの起動だけ。
リリースの資料（`release/`）の書き出しと、納品物を外すときの `mindmap.yaml` の編集は、Claude Code が書き込みの確認を出す。資料の本文（`docs/`）は `add`・`update` の `body_markdown` で書くので、確認は出ない。

## 進め方ガイド

分野ごとの進め方の手引きで、`skills/mindmap/playbooks/` に置く。
どの進め方ガイドも、フェーズの並び・フェーズごとの観点・必ず調べるもの・ゴールの候補・リリースの形を、同じ項目立てで持つ。
手引きの意味は [話し合いの進め方](../はじめに/コアコンセプト/話し合いの進め方.md#進め方ガイド) にある。

| 分野 | 最上位の軸の呼び名 | フェーズ |
| --- | --- | --- |
| システム開発 | システム | 目的 → 要件 → 構成 → インターフェース → コンテンツ |
| 調査 | 調査対象 | 問い → 観点 → 事実 → 評価 → 結論 |
| 資料作り | 資料 | 目的 → 読み手 → 構成 → コンテンツ → 仕上げ |
| 壁打ち | テーマ | 問い → 発散 → 整理 → 絞り込み → 結論 |

システム開発のゴールの候補は、要件まで・インターフェースまで（既定）・モジュール構成まで。
進め方ガイドの置き場所は [playbooks](https://github.com/shuhei1101/mindmap/blob/develop/skills/mindmap/playbooks/)。
