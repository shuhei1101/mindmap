# 動作環境

mindmap を使う端末に要る条件の一覧。
値の根拠は開発ドキュメントの[非機能要件](https://github.com/shuhei1101/mindmap/blob/develop/dev/%E8%A8%AD%E8%A8%88%E6%9B%B8/%E9%9D%9E%E6%A9%9F%E8%83%BD%E8%A6%81%E4%BB%B6/%E9%9D%9E%E6%A9%9F%E8%83%BD%E8%A6%81%E4%BB%B6.yaml)にある。

## スキルとスクリプト

| 項目 | 条件 | 補足 |
| --- | --- | --- |
| Claude Code | 2.1.287 以上 | これより古い版は確かめていない |
| OS | Linux・macOS・Windows（WSL を含む） | 確かめたのは WSL2 の Ubuntu 24.04 |
| Python | 3.12 以上 | 古いときは依存の確認（`check-env`）が作り直すコマンドを返す |
| 通信 | 不要 | スクリプトはワークスペースのファイルを読み書きするだけ |

## プレビュー

| 項目 | 条件 | 補足 |
| --- | --- | --- |
| 通信 | CDN へ HTTPS で届くこと | 描画のライブラリを開いたときに CDN から読む |
| 項目の数 | 1000 件まで | つながり（3D）がなめらかに動くことを確かめた件数 |
| 空きメモリ | 2GB 以上 | 1000 件のつながりで、ブラウザ全体が最大 1.5GB ほど使う |
| 描画 | ブラウザの描画の支援（GPU）が効いていること | 支援が効かないと、67 件でもつながりの動きが落ちる |
