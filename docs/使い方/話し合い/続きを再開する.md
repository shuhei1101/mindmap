# 続きを再開する

途中まで進んだ話し合いを再開するとき、セットアップのスキル `setup` で状況を読んで、続きから進める。

## 前提

- [プラグインをインストールする](../セットアップ手順/プラグインをインストールする.md)
- [セットアップから始める](./セットアップから始める.md)で作った、`mindmap.yaml` があるワークスペース

## 手順

### スキルを呼ぶ

Claude Code で、ワークスペースのフォルダを渡して呼ぶ。

```
/mindmap:setup {ワークスペースのフォルダ}
```

`mindmap.yaml` があるフォルダは既存のワークスペースとして扱われ、どのファイルも書き換えられない。

### 状況を読む

`setup` が、次の状況を示し、続きを推奨する。
再開したい話題を伝えていれば、そこから続ける推奨になる。

| 状況 | 中身 |
| --- | --- |
| 要見直し | 方針転換で見直しが要る検討事項 |
| 進行中 | 進めているタスク |
| 再開可能 | 保留で、依存先が全て決着した検討事項・タスク |
| 次の候補 | 前提が揃った未決定。フェーズ → 影響度 → 後続の件数の順 |

状況の元は [再開時の状況を読む](../../リファレンス/コマンド.md#再開時の状況を読む)。

### 話し合いへ進む

`setup` の案内のとおり、話し合いを進めるスキルを呼ぶ。

```
/mindmap:session {ワークスペースのフォルダ}
```

既存の項目の ID は変わらず、続きの番号で項目が足される。
