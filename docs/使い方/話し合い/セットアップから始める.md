# セットアップから始める

新しい話し合いを始めるとき、セットアップのスキル `setup` でワークスペースを作る。

## 前提

- [プラグインをインストールする](../セットアップ手順/プラグインをインストールする.md)
- 話し合いの記録を置く、まだ `mindmap.yaml` が無いフォルダ

## 手順

### スキルを呼ぶ

Claude Code で、ワークスペースにするフォルダを渡して呼ぶ。

```
/mindmap:setup {ワークスペースのフォルダ}
```

フォルダを渡さないと、指定を求められる。
指定が決まらないうちは、何も書かれない。

### 依存を確かめる

`setup` が最初に、スクリプトの依存を確かめる。
足りないと、足りないものとそろえるコマンドが示されて止まる。
示されたコマンドを実行してから、もう一度呼ぶ（[スクリプトの依存を入れる](../セットアップ手順/スクリプトの依存を入れる.md)）。

### 分野とゴールを決める

`setup` が、進め方ガイドから、分野・最上位の軸の呼び名・フェーズ・カテゴリー・ゴールのたたき台を示す。
たたき台を直して確定すると、ワークスペースが作られ、プレビューが書き出される。

分野ごとの既定は [話し合いの進め方](../../はじめに/コアコンセプト/話し合いの進め方.md#進め方ガイド) にある。

### 話し合いへ進む

`setup` の最後の案内のとおり、話し合いを進めるスキルを呼ぶ。

```
/mindmap:session {ワークスペースのフォルダ}
```

## 結果

フォルダに `mindmap.yaml`・種類ごとの空の YAML・`docs/`・`handoff/`・`preview.html` ができる。
ファイル構成は [ワークスペースの書式](../../リファレンス/ワークスペースの書式.md#ファイル構成) にある。
