# プラグインをインストールする

mindmap を初めて使うときに実行する。

## 前提

Claude Code 2.0.12 以上が入っている。

## 手順

### マーケットプレイスを登録する

```bash
claude plugin marketplace add shuhei1101/mindmap
```

登録しないと、次のインストールで `mindmap@mindmap` が見つからない。

### プラグインをインストールする

```bash
claude plugin install mindmap@mindmap
```

`@` の後ろを省くと、同じ名前のプラグインを持つ別のマーケットプレイスから入ることがある。

## 反映

`再起動`（起動中の Claude Code のセッションを閉じて開き直す）。

## 確認

#### マーケットプレイスが登録されている

```bash
claude plugin marketplace list
```

`mindmap` が出る。

#### プラグインが有効になっている

```bash
claude plugin list
```

`mindmap@mindmap` が有効で出る。

## 元に戻す

インストールを戻してから、マーケットプレイスの登録を外す。

```bash
claude plugin uninstall mindmap@mindmap
claude plugin marketplace remove mindmap
```

ワークスペース（話し合いを記録したフォルダ）は消えずに残る。
要らなければ手で消す。
