# スクリプトの依存を入れる

mindstella のスクリプトを初めて動かすとき、`check-env` が足りないものを返したときに実行する。

## 前提

- [プラグインをインストールする](./プラグインをインストールする.md)
- Python 3.12 以上（`venv` を含む）が入っている

## 手順

### Python の版を確かめる

```bash
python3 --version
```

`Python 3.12` 以上と出る。
これより古いと、`check-env` が `base_python_ok: false` を返し、仮想環境を作るコマンドを出さない。

### スキルのフォルダを引く

```bash
find ~/.claude/plugins/cache -path '*/skills/mindmap/scripts/mindmap.py'
```

出たパスから末尾の `/scripts/mindmap.py` を除いたものが `{スキルのフォルダ}`。
複数出たら、版のフォルダが新しい方を使う。
何も出ないときは、プラグイン mindstella がインストールされていない。

### 仮想環境を作ってライブラリを入れる

```bash
python3 {スキルのフォルダ}/scripts/mindmap.py check-env
```

出力の `install` に出たコマンドを、そのまま実行する。
スキル専用の仮想環境 `~/.mindmap/venv`（Windows は `%USERPROFILE%\.mindmap\venv`）を作り、PyYAML・jsonschema を入れる。
Ubuntu・Debian で `ensurepip is not available` と出たら、`sudo apt install python3-venv` を実行してから入れ直す。

### コマンドを起動する

```bash
python3 {スキルのフォルダ}/scripts/mindmap.py {コマンド} --workspace {フォルダ}
```

どのコマンドもシステムの `python3` で起動する。
起動した Python に依存が揃っていなければ、`~/.mindmap/venv` の Python で自動的に起動し直す。
仮想環境が無いと、終了コード 1 で `check-env` を促すエラーが出る。

## 反映

即時。

## 確認

#### 依存が揃っている

```bash
python3 {スキルのフォルダ}/scripts/mindmap.py check-env
```

終了コード 0 で、出力の `venv_ok`・`python_ok` と全ての `packages[].ok` が `true`、`install` が `null` になる。
足りないものがあると終了コード 1 で、`install` に入れるコマンドが出る。
そのコマンドを実行してから、この確認をやり直す。

## 元に戻す

仮想環境のフォルダを消す。

```bash
rm -rf ~/.mindmap/venv
```

外すと、起動した Python に依存が無い限り、`check-env` 以外のコマンドは動かなくなる。
ワークスペース（話し合いを記録したフォルダ）は消えずに残る。
