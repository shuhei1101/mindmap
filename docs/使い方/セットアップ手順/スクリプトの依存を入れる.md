# スクリプトの依存を入れる

mindmap のスクリプトを初めて動かすとき、`check-env` が足りないものを返したときに実行する。

## 前提

- [プラグインをインストールする](./プラグインをインストールする.md)
- Python 3.12 以上と pip が入っている

## 手順

### Python の版を確かめる

```bash
python3 --version
```

`Python 3.12` 以上と出る。
これより古いと、`check-env` が `python_ok: false` を返して終わる。

### ライブラリを入れる

```bash
python3 -m pip install 'PyYAML>=5.1' 'jsonschema>=4.18.0'
```

どちらかが下限より古いと、ワークスペースを読み書きするコマンドが動かない。

## 反映

即時。

## 確認

#### 依存が揃っている

```bash
python3 {スキルのフォルダ}/scripts/mindmap.py check-env
```

終了コード 0 で、出力の `python_ok` と全ての `packages[].ok` が `true`、`install` が `null` になる。
足りないものがあると終了コード 1 で、`install` に入れるコマンドが出る。
そのコマンドを実行してから、この確認をやり直す。

## 元に戻す

ライブラリを外す。

```bash
python3 -m pip uninstall PyYAML jsonschema
```

外すと、`check-env` 以外のコマンドは動かなくなる。
ワークスペース（話し合いを記録したフォルダ）は消えずに残る。
