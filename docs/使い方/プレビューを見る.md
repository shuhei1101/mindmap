# プレビューを見る

話し合いの記録を、書き出した `preview.html` をブラウザで開いて読み返す。
プレビューは読み返す画面で、記録は書き換えられない。

## 前提

- [セットアップから始める](./話し合い/セットアップから始める.md)で作った、`mindmap.yaml` があるワークスペース
- [動作環境](../リファレンス/動作環境.md#プレビュー)を満たすブラウザ

## 手順

### プレビューを書き出す

ワークスペースを編集したステップは、最後に `build` を流して `preview.html` を書き出し直す。
直した記録を読み返したいときは、`session` にプレビューの書き出しを頼む。
`session` が `preview.html` の絶対パスを示す。ブラウザは自動では開かない。

### ブラウザで開く

`preview.html` をブラウザで開く。サーバーは要らない。
開くと概要が出る。

描画のライブラリと文字を、開いたときにネットから読む。
読めなかったライブラリがあると、それを使う箇所に名前が出る。

### 画面を移る

上のトップバーに、話し合いの題名・検索・ライトとダークの切り替えと、画面を移るタブの帯がある。
タブの帯で、概要・検討事項・タスク・調査・資料・用語集・メモ・会話ログを移る。タブには、アイコンと項目の件数が付く。
つながりは、帯の右端から開く。
タブを移っても、開いていた詳細パネルは閉じない。

URL のハッシュに、画面と開いている項目が入る。
同じ URL を開き直すと、同じ画面と項目が開く。
ブラウザの戻る・進むで、見てきた画面へ戻れる。

| 画面 | 見方 |
| --- | --- |
| 概要 | タイルで状況を見る |
| 検討事項 | マップ（既定）・ボード・表を切り替える |
| タスク | ボード（既定）・表を切り替える |
| 調査・用語集・メモ・会話ログ | 表で見る |
| 資料 | カード（既定）・ボード・表を切り替える |
| つながり | 全種類の項目を 3D でつないで見る |

### 概要で状況を見る

概要は、次のタイルを並べる。

| タイル | 中身 |
| --- | --- |
| 次に検討する項目 | 前提が全て決着した未決定の検討事項。タイルに収まるだけ並ぶ |
| ゴールまで | ゴールのフェーズまでの決定済みの数・フェーズごとの棒・成果物のチェックリスト |
| 要見直し | 要見直しの検討事項 |
| 保留 | 保留の検討事項の名前 |
| 進行中のタスク | 進行中のタスク |
| カテゴリー別の進み具合 | カテゴリーを行、フェーズを列にした表 |

項目を押すと、詳細パネルが開く。
「すべて表示」と、進み具合のセルを押すと、その条件で絞った表を開く。
成果物が 5 件を超えたときは、「すべて表示」で成果物の資料を開く。

### 検討事項のマップを辿る

マップは、対象・カテゴリー・フェーズ・検討事項を木で描く。
次の操作ができる。

- 状態の印を押して、状態ごとに表示・非表示を切り替える。既定では決定済み・対象外・取り下げが隠れている
- キーワードを入れて、名前に含む項目を黄色で強調する。当たった項目を含む状態の印に、件数のバッジが付く。非表示の状態の項目も数える
- 項目を押して、根までの枝と前提・後続の線を強調する。ほかは薄くなり、詳細パネルが開く
- 背景をドラッグして動かす。拡大・縮小・全体を表示のボタンは、マップの枠の外にある

幅 900px 以下では、マップは字下げした縦の一覧になる。

### 表で絞り込む

どの表でも、同じ操作ができる。

| 操作 | やり方 |
| --- | --- |
| 並べ替える | 列の見出しを押す。昇順 → 降順 → 解除の順に変わる |
| 絞り込む | 列の見出しから値を選ぶ。値ごとの件数が出る。かかっている条件はチップで出て、1 つずつ・全部を外せる |
| 列を固定する | 列の見出しのピンのボタンを押す。左端から押した列までが、横に送っても固定される。固定中の列をもう一度押すと外れる |
| 表示する列を選ぶ | 表示する列の選択で、列を付け外しする。タイトルの列は外せない |
| 初期設定に戻す | 表示する列の選択から、列・並べ替え・固定を初期設定に戻す |

操作しても、スクロールの位置は変わらない。
表で絞り込んだ条件は保存されない。概要から絞って開いたときだけ、その条件のチップが付いた状態で開く。
表示する列は、この端末に残る。

### 資料を読む

資料のカードは、成果物を先頭に、成果物の印付きで並ぶ。
カードと表に、資料の状態（下書き・確認中・完成）が出る。
カードとボードの絞り込みでは、成果物・状態・種類・カテゴリー・フェーズ・タグで絞れる。
ボードは、資料を状態（下書き・確認中・完成）の列に並べる。
資料が 0 件の列も出る。
ボードの列の中も、成果物を先頭に並ぶ。

### 詳細を読む

項目を押すと、詳細パネルが右から出る。
幅 1100px 以上（マップは 901px 以上）では、本文を寄せて並べる。それより狭いと、本文に重なる。

詳細パネルは、次を出す。

- 項目の ID・タイトル・状態。成果物の資料にはタイトルの右に印が付く
- 検討事項の案。採用・不採用と理由を、カードの縦並びで出す
- 本文。Markdown と mermaid の図を描く
- 前提・後続の項目・関連タスク・経緯・関連・この項目を参照している項目。押すとその項目へ移る

項目を移ると履歴に積まれ、見出しの「← →」とブラウザの戻る・進むで、見てきた項目を行き来できる。
閉じるには、閉じるボタンか Esc を使う。

「全画面に切り替える」を押すと、画面の中央に大きく出る。
元の大きさに戻すには、「元の大きさに戻す」か外側を押す。

図には、次のボタンがある。

| ボタン | 動き |
| --- | --- |
| 拡大して見る | 図を大きく開く。ホイールで拡大・縮小し、背景のドラッグで動かす。図の文字は選んでコピーできる |
| Raw | 図と mermaid の原文を切り替える |
| コピー | mermaid の原文をクリップボードに写す |

### つながりを辿る

つながりは、全種類の項目を、依存・関連・根拠・進めるタスクの関連でつないで 3D で描く。
次の操作ができる。

- 上下左右にドラッグして回す。操作が止まってしばらくすると、ゆっくり自動で回る
- ホイールで、マウスの位置へ寄る。背景をダブルクリックすると、元の位置に戻る
- 玉にカーソルを乗せると、つながる玉が少し寄ってきて、ほかは薄くなる
- 玉を押すと、そこへ寄って詳細パネルが開き、つながる線の上を小さな玉が流れる
- 項目の種類ごとに、表示・非表示を切り替える

扱える項目は 1000 件まで。
描画の速さの条件は、[動作環境](../リファレンス/動作環境.md#プレビュー)にある。

### 項目を検索する

トップバーの検索を押すか、`/` を押す。
ID・タイトル・本文を、空白で区切った語を全て含むもので探す。大文字・小文字は区別しない。
結果を押すか、矢印で選んで Enter を押すと、その項目のタブと詳細パネルが開く。
閉じるには、Esc か外側の押下を使う。

### ライトとダークを切り替える

トップバーのボタンで、ライトとダークを切り替える。
選んだほうは、この端末に残る。
