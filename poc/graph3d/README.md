# PoC: つながりの描画の重さ

つながり（3D）の自前のキャンバス描画が、項目の数の段ごとに拡大・縮小・回転・押下で 1 コマに収まるかを測る。

| ファイル | 中身 |
| --- | --- |
| `index.html` | 検証用のページ。見本の描画・地・詳細パネル・本文の寄せを写し、合成データを `?n=` 件で描く |
| `measure.py` | Playwright（Python）で Chromium を開き、操作ごとに記録してまとめる |
| `results/results.jsonl` | 計測の結果（1 行 1 条件） |

## 実行

```bash
python3 measure.py results/results.jsonl opt,opt-settle,mock
```

描き方の名前:

| 名前 | 中身 |
| --- | --- |
| `opt` | 見本の作りから、毎コマの `Map` の作り直しと並べ替えの配列の作り直しを外したもの。描画領域は幅が変わるたびに作り直す（見本と同じ） |
| `opt-settle` | `opt` のうち、描画領域の作り直しを幅の変化が止まってから 1 回にしたもの（押下の落ちたコマの切り分け用） |
| `mock` | 見本の毎コマの割り当てのまま |
